<summary>
- The library gains a backend-independent notion of a conversation that outlives one request: a session you open by id, send a prompt to, and close.
- It also gains the HTTP surface those sessions are served through — readiness, metrics and prompt intake on one port — so a second interactive agent image no longer has to copy that routing by hand.
- Every route, status code, header name, body cap and readiness string behaves exactly as the one image that serves them today; that contract is frozen and unchanged.
- A request carrying no session header is served from the default conversation exactly as today, so nothing already talking to the service is orphaned.
- A request carrying a session id runs in its own conversation: two different ids run at the same time, two requests on one id take turns, and no request is ever rejected because of the locking.
- A malformed or empty session id is refused before the request body is read and before any conversation is created.
- Each turn writes two log lines — one when it starts, one when it ends — so per-conversation serialisation is visible in the pod log without exposing prompt content.
- The prompt itself is never logged; only its byte length and a short digest are.
- The frozen contract is written down in a new document, so both consumers honour the same interface after this work is done.
</summary>

## 1. The session seam — new file `agent_session.go` (repository root, `package lib`)

Create `agent_session.go` at the repository root with the license header used by every other file in the package, `package lib`, and exactly these two exported interfaces. This is the seam the HTTP surface knows about and the only thing it knows about a backend.

```go
//counterfeiter:generate -o mocks/session.go --fake-name Session . Session

// Session is one conversation with a backend that outlives a single request.
//
// It is the seam the interactive HTTP service depends on: the service holds one
// Session per session id and never learns which backend backs it. A backend
// implements it over whatever mechanism gives it continuity — pi's --session-id,
// a Claude process held open — and a backend that holds nothing between turns
// still satisfies it, because Close may be a no-op.
type Session interface {
	// Prompt sends one turn to the conversation and returns that turn's result.
	Prompt(ctx context.Context, prompt string) (string, error)

	// Close releases the resources the conversation holds. It is called when the
	// session is no longer needed and must be safe to call once; an implementation
	// that holds nothing returns nil.
	Close(ctx context.Context) error
}

//counterfeiter:generate -o mocks/session-factory.go --fake-name SessionFactory . SessionFactory

// SessionFactory builds the Session for one session id.
//
// Create is construction only: it performs no I/O and cannot fail, so a session
// exists exactly when a caller addresses it and an unseen id starts a fresh
// conversation with no registration step. Any failure a backend can have
// surfaces from Session.Prompt, where the HTTP service already has a defined
// failure path.
type SessionFactory interface {
	// Create returns the session for id, building it on first use.
	Create(id string) Session
}
```

## 3. The per-id cache and the two-level lock — new file `interactive/session-cache.go`

Two unexported types and three functions. The locking discipline is the whole point of this file; get it exactly right.

```go
// sessionEntry is one conversation plus the lock that serializes its turns.
type sessionEntry struct {
	id      string
	session agentlib.Session
	mu      sync.Mutex
}

// Prompt runs one turn on this conversation, serialized against every other turn on
// the same session and bracketed by the turn-boundary log pair.
//
// The window between the two log lines is exactly the lock-held window, which is what
// makes per-session serialisation observable from outside the process. turn end is
// emitted whenever the runner returns, including when it returns an error; a panic
// inside the runner is the one case that skips it, and the deferred unlock still
// releases the lock so the next request on this id does not deadlock.
func (e *sessionEntry) Prompt(ctx context.Context, prompt string) (string, error) {
	e.mu.Lock()
	defer e.mu.Unlock()
	glog.V(2).Infof("turn start id=%s", e.id)
	result, err := e.session.Prompt(ctx, prompt)
	glog.V(2).Infof("turn end id=%s", e.id)
	return result, err
}

// sessionCache holds one entry per session id, built on first use and never evicted.
type sessionCache struct {
	factory agentlib.SessionFactory
	mu      sync.Mutex
	byID    map[string]*sessionEntry
}

// newSessionCache creates an empty cache over factory.
func newSessionCache(factory agentlib.SessionFactory) *sessionCache {
	return &sessionCache{factory: factory, byID: map[string]*sessionEntry{}}
}

// Get returns the entry for id, building and caching it on first use.
//
// The map lock guards the map and nothing else: it is released before the caller takes
// the entry's own lock, so two different sessions never contend here and one session's
// slow turn cannot delay another's lookup. Entries are never evicted; the id space is
// operator-controlled and the surface is namespace-scoped (spec 054, Security).
func (c *sessionCache) Get(id string) *sessionEntry {
	c.mu.Lock()
	defer c.mu.Unlock()
	entry, ok := c.byID[id]
	if !ok {
		entry = &sessionEntry{id: id, session: c.factory.Create(id)}
		c.byID[id] = entry
	}
	return entry
}
```

The two-level property is load-bearing and is asserted by tests (requirement 8c): the map lock is held ONLY across the map read/write in `Get` and is released before the caller takes `entry.mu`. Never hold both at once.

Imports for this file: `context`, `sync`, `agentlib "github.com/bborbe/agent"`, `github.com/golang/glog`.

## 4. Session-id resolution — new file `interactive/session-id.go`

```go
// sessionHeader is the request header a caller uses to address a session. Callers
// depend on the exact spelling, so it is a constant rather than a repeated literal.
const sessionHeader = "X-Session-Id"

// defaultSessionID is the conversation a request without the header is served from.
const defaultSessionID = "identity"

// sessionIDPattern is the allowed session id format: one to 64 characters, the first
// of which is not '-'. This is the security boundary, not a style preference — the id
// reaches a backend CLI as a command-line argument, so a leading '-' would be parsed
// as a flag, and '.' or '/' would escape a session directory if the id were used to
// build a storage path.
var sessionIDPattern = regexp.MustCompile(`^[A-Za-z0-9_][A-Za-z0-9_-]{0,63}$`)
```

```go
// sessionIDFromRequest resolves the conversation a prompt belongs to from the
// request's session header.
//
// An absent header is an existing caller and resolves to defaultSessionID, the one
// conversation this service served before the header existed, so nothing already
// talking to it is orphaned. A present header is the caller's own id and is accepted
// only if it matches sessionIDPattern — validated here, before any body is read and
// before any session exists.
//
// Absent and present-but-empty are deliberately different outcomes, and
// http.Header.Values is what tells them apart: Get collapses both to "". An empty
// value is a present header that does not match, so it is an error.
//
// The returned error deliberately does not carry the id: the id is caller-supplied,
// and a rejected id in a log line would let the log enumerate what callers asked for.
func sessionIDFromRequest(r *http.Request) (string, error) {
	values := r.Header.Values(sessionHeader)
	if len(values) == 0 {
		return defaultSessionID, nil
	}
	if !sessionIDPattern.MatchString(values[0]) {
		return "", errors.Errorf(r.Context(), "session id does not match the allowed format")
	}
	return values[0], nil
}
```

Only the FIRST value of a repeated header is considered, exactly as above. Imports for this file: `net/http`, `regexp`, `github.com/bborbe/errors`.

## 5. The prompt handler — new file `interactive/prompt.go`

```go
// maxPromptBytes bounds the body a single /prompt request may carry. The endpoint is
// unauthenticated and reachable by anything in the namespace, so an unbounded read
// would let one caller exhaust the pod's memory.
const maxPromptBytes = 1 << 20
```

`func (s *service) promptHandler() http.Handler` returns an `http.HandlerFunc` that performs these steps IN THIS ORDER — the order is the contract, because a rejected request must not build a session, read the body, or emit a turn line:

1. `if r.Method != http.MethodPost { http.Error(w, "POST required", http.StatusMethodNotAllowed); return }` — a non-POST on `/prompt` is 405.
2. `sessionID, err := sessionIDFromRequest(r)`; on error `http.Error(w, "invalid session id", http.StatusBadRequest)` and return. This happens BEFORE the body is read and before any session exists.
3. `body, err := io.ReadAll(io.LimitReader(r.Body, maxPromptBytes))`; on error `http.Error(w, fmt.Sprintf("read prompt: %v", err), http.StatusBadRequest)` and return. The `io.LimitReader` wraps the body BEFORE it is buffered — an oversized request must never be read into memory whole. The cap TRUNCATES and processes; it never rejects.
4. `prompt := strings.TrimSpace(string(body))`; `if prompt == "" { http.Error(w, "empty prompt", http.StatusBadRequest); return }`.
5. Log the prompt's size and digest and NOTHING else about it — never the content, and never the session id on this line:
   ```go
   	digest := sha256.Sum256([]byte(prompt))
   	glog.V(2).Infof(
   		"prompt intake: bytes=%d sha256=%s",
   		len(prompt),
   		hex.EncodeToString(digest[:8]),
   	)
   ```
6. `entry := s.cache.Get(sessionID)` then `result, err := entry.Prompt(r.Context(), prompt)`. The map lock inside `Get` is released before `entry.Prompt` takes the session lock — never restructure this so both are held.
7. On error: `glog.Warningf("prompt intake failed: %v", err)` and `http.Error(w, "prompt failed", http.StatusInternalServerError)`. The wrapped error is logged and NEVER returned to the caller; the caller sees the fixed string `prompt failed`.
8. On success: `w.Header().Set("Content-Type", "text/plain; charset=utf-8")` and `_, _ = fmt.Fprint(w, result)`.

Imports for this file: `crypto/sha256`, `encoding/hex`, `fmt`, `io`, `net/http`, `strings`, `github.com/golang/glog`.

## 6. Readiness — new file `interactive/readiness.go`

```go
// readinessDialTimeout bounds the provider dial a readiness probe performs.
const readinessDialTimeout = 5 * time.Second
```

`func (s *service) readinessHandler() http.Handler` returns an `http.HandlerFunc`:

- When `s.providerBaseURL == ""`: `w.WriteHeader(http.StatusOK)` then `_, _ = fmt.Fprint(w, "OK (PROVIDER_BASE_URL unset — provider reachability not checked)")`. That body string is byte-for-byte frozen — it contains a single em dash (U+2014) between `unset` and `provider`. Copy it exactly; a hyphen or an en dash is a contract break.
- Otherwise `addr, err := dialAddress(r.Context(), s.providerBaseURL)`; on error `http.Error(w, err.Error(), http.StatusServiceUnavailable)` and return.
- Then `conn, err := net.DialTimeout("tcp", addr, readinessDialTimeout)`; on error `http.Error(w, fmt.Sprintf("provider unreachable at %s: %v", addr, err), http.StatusServiceUnavailable)` and return.
- On success `_ = conn.Close()`, `w.WriteHeader(http.StatusOK)`, then `_, _ = fmt.Fprintf(w, "OK (provider reachable at %s)", addr)`.

The probe DIALS rather than calling the API: the question a readiness probe asks is "can this agent reach its provider at all", and a dial answers it without spending a request or needing a valid key. Pointing the URL at an unroutable address must turn the probe red, or it is only testing that the process is alive.

```go
// dialAddress turns a provider base URL into a host:port to dial, defaulting the port
// from the scheme so "https://host" and "host" both work.
func dialAddress(ctx context.Context, raw string) (string, error) {
	parsed, err := url.Parse(raw)
	if err != nil {
		return "", errors.Wrapf(ctx, err, "parse provider base url %q", raw)
	}
	host := parsed.Host
	if host == "" {
		// No scheme — treat the whole value as host[:port].
		host = raw
	}
	if !strings.Contains(host, ":") {
		if parsed.Scheme == "http" {
			host += ":80"
		} else {
			host += ":443"
		}
	}
	return host, nil
}
```

`dialAddress` takes the caller's `context.Context` — never `context.Background()`.

Imports for this file: `context`, `fmt`, `net`, `net/http`, `net/url`, `strings`, `time`, `github.com/bborbe/errors`.

```go
// captureStderr redirects the process's stderr into a buffer for the duration of fn
// and returns what was written. glog's stderr sink reads os.Stderr when it emits, so
// the swap is observed as long as -logtostderr is on.
func captureStderr(fn func()) string {
	old := os.Stderr
	r, w, err := os.Pipe()
	Expect(err).To(BeNil())
	os.Stderr = w
	defer func() { os.Stderr = old }()

	done := make(chan string, 1)
	go func() {
		var buf bytes.Buffer
		_, _ = io.Copy(&buf, r)
		done <- buf.String()
	}()

	fn()

	Expect(w.Close()).To(Succeed())
	os.Stderr = old
	return <-done
}
```

Start the service through its constructor with an empty provider base URL and an empty `prometheus.NewRegistry()`, wrap its handler in `httptest.NewServer`, and assert `GET /readiness` is 200, `GET /metrics` is 200 and `POST /prompt` (with a session fake returning a known string) is 200. This is the named subtest AC1's evidence names.

### 8c. The frozen-contract table — spec AC2

One `DescribeTable` in the `interactive_test` package, with one `Entry` per row below. Each entry carries the request shape (method, path, whether the session header is set and to what, the body, the provider base URL the service was built with) and a `verify func(resp *http.Response, body string)` closure so a row can assert its own specifics. Every row must be a named subtest; a single monolithic `It` does not satisfy AC2.

| # | Request | Expected |
|---|---|---|
| 1 | `GET /readiness`, provider base URL unset | 200, body EXACTLY `OK (PROVIDER_BASE_URL unset — provider reachability not checked)` (em dash U+2014) |
| 2 | `GET /readiness`, provider base URL `http://127.0.0.1:1` | 503 |
| 3 | `GET /metrics` | 200 |
| 4 | `GET /prompt` | 405 |
| 5 | `POST /prompt`, no `X-Session-Id` | 200, and `factory.CreateArgsForCall(0)` equals `"identity"` |
| 6 | `POST /prompt`, header `X-Session-Id` present but empty | 400 |
| 7 | `POST /prompt`, header `X-Session-Id: bad id!` | 400 |
| 8 | `POST /prompt`, body `strings.Repeat("a", 2<<20)` | 200, and the prompt the session received is exactly `1 << 20` bytes |
| 9 | `POST /prompt`, empty body | 400 |
| 10 | `POST /prompt`, valid body, no header | 200, response `Content-Type` exactly `text/plain; charset=utf-8`, body equal to the session fake's returned string |

Row 8 reads the prompt back with `session.PromptArgsForCall(0)` (the counterfeiter fake returns `(context.Context, string)`). Use `http://127.0.0.1:1` for the unroutable row: the dial is refused immediately rather than hanging for the 5-second timeout.

### 8d. Two-level locking — spec AC3, two named subtests

Both subtests install `factory.CreateStub = func(id string) agentlib.Session { ... }` returning a fresh `&mocks.Session{}` whose `PromptStub` signals a `started chan string` and then blocks on a `release chan struct{}`.

- `It("distinct ids overlap", ...)` — fire two concurrent `POST /prompt` requests with two DIFFERENT session ids. Assert both reach the session stub (two receives on `started`, or `atomic.LoadInt32(&running) == 2`) BEFORE `release` is closed, then close `release` and assert both responses are 200. This subtest fails if the map lock is still held while a session lock is taken, because the second request would never reach its own session.
- `It("same id serialises", ...)` — fire one request on id `abc`, wait for `started`; fire a second request on the SAME id; assert `Consistently(started, 200*time.Millisecond).ShouldNot(Receive())` and that `factory.CreateCallCount()` is 1 (the cache reused the entry); then close `release` and assert the second turn eventually starts and both responses are 200.

### 8e. The turn-boundary log pair — spec AC4, two named subtests

- `It("turn pair emitted", ...)` — with a session fake that returns a known string, wrap a `POST /prompt` on id `abc` in `captureStderr` and assert the captured output contains `turn start id=abc` and `turn end id=abc`, with the `turn start` line's index strictly less than the `turn end` line's index (order, not just presence).
- `It("no turn line for rejected request", ...)` — for each rejection case (header `X-Session-Id: bad id!`, header present but empty, empty body, `GET /prompt`), wrap the request in `captureStderr` and assert the captured output contains no `turn start` substring at all.

### 8f. Failure modes — three more named subtests

- `It("releases the session lock when the runner panics", ...)` — a `CreateStub` whose `PromptStub` panics on its first call and returns a value on the second. Send one `POST /prompt` on id `abc` (ignore the client-side error; net/http recovers the panic and closes that connection), then send a second `POST /prompt` on the SAME id and assert it is 200 with the second stub's value. This is the spec's "the lock is released by a deferred unlock, so the next request on that session does not deadlock" row.
- `It("returns 500 and still closes the turn when the runner fails", ...)` — `session.PromptReturns("", errors.New("boom"))`; assert the response status is 500, the response body is exactly `prompt failed\n` (never the runner's message), and the captured stderr contains both `turn start id=abc` and `turn end id=abc`.
- `It("keeps one cache entry per id and never evicts", ...)` — POST on id `a`, then id `b`, then id `a` again; assert `factory.CreateCallCount()` is 2 and `factory.CreateArgsForCall(0)`/`(1)` are `"a"` and `"b"`.
- `It("keeps serving prompts when the provider is unreachable", ...)` — build the service with `http://127.0.0.1:1`; assert `GET /readiness` is 503 AND a subsequent `POST /prompt` is still 200.

Every goroutine in these tests must be race-free under `-race` (the Makefile's `test` target runs `go test -race`): use channels and `sync/atomic`, never a plain shared counter.
